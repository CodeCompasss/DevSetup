# 🛠️ Essential Developer Tools & Extensions

This list contains a curated selection of essential tools for modern software development, categorized for ease of setup.

## 🖥️ Desktop Applications & GUI Tools
*   **Alacritty**: A modern, GPU-accelerated terminal emulator.
*   **VS Code**: The industry-standard code editor.
*   **Obsidian**: A powerful knowledge base that works on top of a local folder of plain text Markdown files.
*   **VLC**: Versatile open-source media player.
*   **Flameshot**: Powerful yet simple-to-use screenshot software.
*   **Stacer**: Linux system optimizer and monitoring tool.
*   **Timeshift**: System restore utility for Linux.
*   **LocalSend**: Open-source cross-platform file sharing.
*   **Fluent Reader**: Modern desktop RSS reader.
*   **LibreOffice**: Complete open-source office suite.
*   **Ulauncher**: Fast application launcher for Linux.
*   **SafeEyes**: Tool to prevent Eye Strain (RSI).
*   **Tipp10**: Free touch typing tutor.
*   **wl-clipboard**: Command-line copy/paste utilities for Wayland.

## 📊 Data & Specialized IDEs
*   **MySQL Workbench**: Visual tool for database design and management.
*   **Spyder**: Powerful scientific environment written in Python, for Python.

## ⚙️ System Utilities
*   **TLP**: Advanced power management for Linux laptops.

## ⚡ Modern CLI Essentials
*   **bat**: A cat clone with wings (syntax highlighting).
*   **eza**: A modern replacement for `ls`.
*   **fd-find**: A simple, fast and user-friendly alternative to `find`.
*   **fzf**: A general-purpose command-line fuzzy finder.
*   **ripgrep (rg)**: An extremely fast alternative to `grep`.
*   **zoxide**: A smarter `cd` command.
*   **tldr**: Simplified and community-driven man pages.
*   **btop**: A game-like terminal resource monitor.
*   **plocate**: A much faster `locate` command.
*   **rsync**: Fast, versatile, remote (and local) file-copying tool.
*   **tree**: Recursive directory listing command.
*   **aria2**: A lightweight multi-protocol & multi-source command-line download utility.
*   **ffmpeg**: A complete, cross-platform solution to record, convert and stream audio and video.
*   **jdupes**: A powerful duplicate file finder.
*   **mc (Midnight Commander)**: Visual file manager for the terminal.
*   **pandoc**: The universal document converter.
*   **samba**: Standard Windows interoperability suite of programs for Linux and Unix.
*   **apache2-utils**: Useful utilities for web server benchmarking (like `ab`).

## 🛠️ Terminal UI (TUI) & Multiplexers
*   **GitHub CLI (gh)**: GitHub’s official command line tool.
*   **lazygit**: A simple terminal UI for git commands.
*   **lazydocker**: A simple terminal UI for docker and docker-compose.
*   **zellij**: A terminal workspace with batteries included.
*   **tmux**: Terminal multiplexer for persistent sessions.
*   **neovim**: Hyperextensible Vim-based text editor.

## 🌐 Runtimes & SDKs
*   **Node.js**: JavaScript runtime built on Chrome's V8.
*   **Python**: Versatile high-level programming language.
*   **Java (JDK)**: Standard platform for building applications and tools.
*   **Rust (rustup)**: Modern language focused on safety and performance.
*   **PHP**: Popular general-purpose scripting language for web development.

## 🏗️ Low-Level & Build Tools
*   **Bison**: General-purpose parser generator.
*   **Flex**: Fast lexical analyzer generator.
*   **NASM**: 80x86 assembler designed for portability and modularity.
*   **Doxygen**: Standard tool for generating documentation from annotated C++ sources.

## 🛡️ Cybersecurity Essentials (for Engineers)
*   **Nmap**: Network mapper for security auditing.
*   **Wireshark**: The world’s foremost network protocol analyzer.
*   **Burp Suite (Community)**: Web application security testing platform.
*   **Gobuster**: Tool used to brute-force URIs and DNS subdomains.
*   **Nikto**: Open source web server scanner.

## ☁️ DevOps & Cloud Infrastructure
*   **Docker**: OS-level virtualization to deliver software in containers.
*   **Kubectl**: Command line tool for controlling Kubernetes clusters.
*   **Helm**: The package manager for Kubernetes.
*   **Terraform**: Infrastructure as Code (IaC) tool.
*   **Ansible**: IT automation tool that configures systems and deploys software.
*   **AWS CLI / GCloud CLI**: Essential tools for cloud provider management.

## 🌍 Web Browsers
*   **Google Chrome**: Fast, secure, and free web browser.
*   **Mozilla Firefox**: Privacy-focused open-source browser.
*   **Brave Browser**: Privacy-focused browser that blocks ads and trackers by default.

## 🧩 VS Code Extensions
### Core Productivity
*   **Prettier**: Opinionated code formatter.
*   **ESLint**: Integrates ESLint into VS Code.
*   **Path Intellisense**: Visual Studio Code plugin that autocompletes filenames.
*   **Auto Rename Tag**: Auto rename paired HTML/XML tag.
*   **TODO Highlight**: Highlight TODO, FIXME and other annotations within your code.
*   **Todo Tree**: Show TODO/FIXME notes in a tree view.
*   **GitLens**: Supercharge Git within VS Code.
*   **Error Lens**: Improve highlighting of errors, warnings and other language diagnostics.
*   **Material Icon Theme**: The most iconic icon theme for Visual Studio Code.

### Advanced Development
*   **Docker**: Makes it easy to build, manage, and deploy containerized applications.
*   **Remote - SSH**: Open any folder on a remote machine using SSH.
*   **Live Server**: Launch a development local Server with live reload feature.
